Botão de ação; primário reservado a UMA ação principal por vista (ex.: "Abrir plano de ação").

```jsx
<Button variant="primary">Abrir plano de ação</Button>
<Button variant="secondary" size="sm">Comparar domínios</Button>
```

Variantes: primary, secondary, ghost, danger. Tamanhos sm/md/lg. `block` para largura total.
