# Marca TOTVS — assets oficiais extraídos (27/07/2026)

## Paleta oficial (CORES/totvscolors.css + .scss + .ase → `assets/cores/`)
PRIMARY: azul-escuro **#002233** · azul **#00dbff**
SECONDARY: roxo **#a44dff**
COMPLEMENTARY: verde **#00ffd4** · limão **#d9ff65** · laranja **#ff8900** · rosa **#ff009e**

Notas de uso na CITADEL:
- #002233 = tinta de marca/títulos (já em uso na direção B).
- #00dbff é neon: contraste 1,6:1 em branco — NUNCA texto em light mode; usar como acento gráfico (linhas de gráfico em dark, marcas, seleção) e derivar tom AA p/ ação em light (petrol-500 #0F5E8C mantido).
- Complementares (laranja/rosa/verde/limão/roxo) = base para derivar semântica AA, não usar cruas em texto.

## Fonte oficial (`assets/fonts/TOTVS-Bold.ttf`)
Família **"TOTVS"**, estilo **Bold**, v1.000 (101KB TTF). SÓ existe o peso Bold no pack → papel: display/wordmark/títulos. Interface e corpo seguem com Archivo; dados com JetBrains Mono. @font-face a declarar nos tokens: `font-family:'TOTVS'; font-weight:700`.

## Logos (`assets/logos/`)
- TOTVS: azul-escuro / branco / preto (SVG + PNG). O SVG azul-escuro/preto usa #012a3a no path (conferir), branco #ffffff.
- BUs (referência de arquitetura de sub-marcas, não usar na CITADEL): TOTVS Gestão, RD Station (SVG azul-escuro + branco).
- Padrão BU: wordmark TOTVS + nome da BU — CITADEL pode seguir "logo TOTVS + CITADEL" no mesmo molde.
